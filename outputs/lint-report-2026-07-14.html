개요

engine/OPERATIONS.md §2 절차에 따라 위키 전체(콘텐츠 페이지 28,300개)를 검진했습니다. engine/scripts/lint.ps1·validate-okf.ps1 기계 점검에, Claude가 직접 수행한 시장 페이지(KOSPI/KOSDAQ) 정합성 의미 점검을 추가했습니다.

이전 리포트 대비: lint-report-2026-07-13에서 발견된 깨진 내부 링크 1,539건은 그 직후 일괄 수정으로 926건까지 감소한 상태였습니다.

⚠️ 정정 안내: 이 리포트 최초 작성 시 “시장 페이지 오등재 24건”으로 보고했으나, 해당 검증 스크립트가 단순 문자열 포함 여부(substring)로만 판단하는 결함이 있어 다른 기업 설명문 안에 우연히 등장한 이름(예: “2대주주 삼성SDI”)까지 오탐지했습니다. 정규식을 줄 시작(^- [...])의 실제 불릿 항목으로 한정해 재검증한 결과 진짜 오등재는 2건이었습니다. 아래 내용은 정정된 결과이며, 이미 즉시 수정을 완료했습니다.

4번 항목 상세: 안전한 append-only 설계로 재시도 성공

이전 2회 시도가 기존 링크 URL 내부 문자열을 오매칭해 콘텐츠를 손상시켰던 것과 달리, 이번에는:

  • 기존 프로즈 텍스트를 전혀 검색·치환하지 않고, 새 불릿 라인만 추가(## 주요 주주/## 경영진 섹션 끝에 삽입, 섹션이 없으면 신규 생성)
  • groups는 frontmatter group: 필드가 비어있을 때만 채움(이미 다른 그룹이 설정된 12건은 충돌로 판단해 건드리지 않고 보존)
  • 회사 파일당 1회만 일괄 반영(1,604개 파일, 2,279개 불릿 + 138개 group 필드 추가)
  • 적용 전 dry-run으로 diff 미리보기 검증, 적용 후 validate-okf.ps1 재검증(위반 4건 그대로 — 신규 위반 없음 확인)

남은 20건은 모두 의도적으로 건드리지 않은 안전한 예외입니다:

  • 12건: 회사가 이미 다른 그룹에 속해 있어 자동 덮어쓰기를 하지 않은 케이스 (예: 롯데지주는 이미 /groups/롯데가 설정되어 있어 LT(롯데투어)와의 역링크는 수동 판단 필요)
  • 5개 대상: 파일명에 공백이 포함된 해외법인(Mayson Partners Pte. Ltd., CJ ENM, Qion Pte. Ltd. 등)이 링크에서 %20으로 인코딩되어 파일 조회에 실패 — 별도 후속 조치 필요

2. 깨진 내부 링크 — %20 인코딩 근본 원인 수정 완료

Resolve-LinkToFile이 URL 인코딩(%20 등)을 디코딩하지 않아 공백 포함 파일명(기업명 신용등급.md) 매칭에 실패하던 문제를 수정했습니다.

lint.ps1의 인바운드 링크 집계(고아 페이지 판정)에도 동일한 디코딩을 추가해 연쇄 효과까지 반영했습니다.
