- 12건: 회사가 이미 다른 그룹에 속해 있어 자동 덮어쓰기를 하지 않은 케이스 (예: 롯데지주는 이미 `/groups/롯데`가 설정되어 있어 `LT(롯데투어)`와의 역링크는 수동 판단 필요)

### 2. 깨진 내부 링크 — `%20` 인코딩 근본 원인 수정 완료

`Resolve-LinkToFile`이 URL 인코딩(`%20` 등)을 디코딩하지 않아 공백 포함 파일명(`기업명 신용등급.md`) 매칭에 실패하던 문제를 수정했습니다.

```powershell
# engine/scripts/_common.ps1 — Resolve-LinkToFile
$rel = [System.Uri]::UnescapeDataString($Link.TrimStart('/'))
```

`lint.ps1`의 인바운드 링크 집계(고아 페이지 판정)에도 동일한 디코딩을 추가해 연쇄 효과까지 반영했습니다.
