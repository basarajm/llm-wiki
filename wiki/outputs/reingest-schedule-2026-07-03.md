## 실행 방식 (승인 없이 자동 진행)

`/loop` 스킬로 동적 페이싱 자동 반복 설정. 매 반복마다:
1. 미완료 배치(P1 → P2 → 이후 정방향 KOSPI 신규 배치 순)에서 최대 12개사를 뽑아 Workflow 실행
   (개별 인제스트 에이전트 병렬 + 병합 에이전트 1개, 기존 IG7~9 패턴 그대로 재사용)
2. 재인제스트(P1·P2)는 `mode: 're-ingest'`로 표시 — 기존 Full 페이지를 덮어쓰되 이미 정확한
   섹션(예: 재무 하이라이트)은 유지하고 "미확인"이었던 항목만 채우도록 지시
3. 배치 완료 시 git commit 자동 수행(커밋 메시지에 `reingest(RG{N})` 또는 `ingest(IG{N})` 접두)
4. `wiki/outputs/ingest-followups.md`·`wiki/log.md`·`wiki/index.md` 갱신
5. 병합 에이전트 실패(API 과부하 등) 시 다음 반복에서 자동 재시도(사용자 개입 불요)
6. P1·P2 완료 후 `local_archive_status.py --market KOSPI --next 12`로 계속 정방향 진행
