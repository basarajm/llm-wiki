## 개요

[1차 시범(대형주 151개사)](/outputs/company-keywords-pilot-2026-07-14) 결과를 바탕으로, 사용자 피드백에 따라
키워드 추출 로직을 고도화한 2차 시범입니다. 1차 표본(151개사) 중 **30개사를 무작위 추출**하여 새 로직을
적용했습니다. 확대 여부 결정을 위한 검토용 결과이며, 아직 기업 페이지 본문에는 반영하지 않았습니다.

## v1 → v2 변경 사항

| 항목 | v1 (1차 시범) | v2 (2차 시범, 본 문서) |
|---|---|---|
| 입력 소스 | frontmatter `description` 한 문장 | 회사 페이지 **본문 전체** (사업 개요·사업 부문·재무 하이라이트·리스크 등) |
| 키워드 개수 | 3-5개 고정 | **최대 10개**, 특이사항 부족하면 5개 내외로 축소 (개수 강제 없음) |
| 뉴스 키워드 | 없음 | **신규**: 웹 검색 기반 최근 뉴스 키워드 4-5개, `(뉴스)` 접미사로 구분 |
| 뉴스 검색 기간 | — | 뉴스량에 따라 가변 — 뉴스 많으면 1개월, 적으면 최대 6개월까지 확대 |
| 처리 방식 | 배치당 12개사 묶어 1개 에이전트 호출 (description만 사용, 웹 검색 없음) | **기업당 1개 에이전트**, Read + WebSearch 도구 직접 사용 |
| 배치당 토큰 | 약 48,000 토큰/12개사 (~4,000/사) | 약 55,000 토큰/1개사 (약 14배) |

**우려/검토 필요 사항**
1. **비용 급증**: v1은 12개사/1콜(~4천 토큰/사)였으나 v2는 1개사/1콜(~5.5만 토큰/사)로 **약 14배** 증가. 151개사 확대 시 약 830만 토큰, 2,463개사 전체 확대 시 약 1.35억 토큰 예상.
