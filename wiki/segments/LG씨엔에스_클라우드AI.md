## 사업 내용

클라우드 도입 진단·전환·설계·구축·운영을 아우르는 클라우드 MSP(Managed Service Provider)
서비스와, AI·빅데이터 기술을 활용한 데이터 분석·Application with AI·AX(AI Transformation)
서비스를 제공한다. 주요 서비스: 클라우드 컨설팅, Cloud Migration/Implementation,
Application Modernization, Cloud Managed Service, AX 컨설팅(AX Discovery), AX 서비스 구현,
AIOps 기반 운영 최적화(Gen AI Factory).

## 주요 제품·서비스

- 클라우드 컨설팅 / Cloud Migration / Application Modernization / Cloud Managed Service
- AX 컨설팅, AX 서비스 구현, AX 서비스 운영 최적화(AIOps)

## 경쟁 현황

글로벌 클라우드서비스제공사(CSP)와의 파트너십을 통한 MSP 경쟁이 치열하며, 국내 SI 3사
(삼성SDS, SK C&C 등)와 클라우드·AI 서비스 시장에서 직접 경쟁 중(세부 점유율 미확인).
