# 드림텍 IMC

## 사업 내용

IT & Mobile Communications(IMC) 사업부는 스마트폰·웨어러블기기 등 IT기기와 데이터센터·서버에 사용되는 각종 PBA(Printed Board Assembly) 모듈을 개발·공급한다. IT Solutions(SUB PBA, Sensor Module, Receiver & Ear jack Module, Power Key/Side Key Module), EMS Solutions(Flexible OLED Display PBA Module, IT기기 완제품·부품 생산 외주 임가공), 그리고 2025년 11월 양산을 개시한 Memory Solutions(DRAM 메모리 모듈 RDIMM/UDIMM/SODIMM, SSD 모듈)로 구성된다.

## 경쟁 현황

Set maker(삼성전자 등 스마트폰·IT기기 제조사)向 부품 공급 구조로, 집적 부품수·모델 변동에 따라 판가가 결정되며 표준화된 시장가격은 존재하지 않는다.
