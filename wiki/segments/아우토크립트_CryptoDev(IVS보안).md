## 사업 내용

차량 암호응용 개발 및 검증 기술(CryptoDev)을 기반으로 자동차 내부시스템(IVS: In-Vehicle System) 보안을 다루는 제품군이다. 크게 (1) 차량 제어기 보안 개발 제품군(AutoCrypt IVS-HSM/TEEL/ASL/IDS 등), (2) 차량 보안 검증 제품군(Security TARA, Security Fuzzer, Security Analyzer, Security Pen Tester 및 관련 컨설팅 서비스), (3) 차량 보안 관리 제품군(vSOC 기반 모니터링·대응)으로 구성된다.

- [Security TARA](/products/Security_TARA)

- Security Fuzzer / Security Analyzer / Security Pen Tester

## 경쟁 현황

주요 부품사(H5사·L5사 등 완성차·부품사向 구축 사례)를 대상으로 사업화. 국내에서는 모회사였던 [펜타시큐리티](/companies/펜타시큐리티)와 기술적 연속성을 가지며, 글로벌 자동차 사이버보안 규제(UNECE/WP.29 UNR155·156) 대응 수요를 기반으로 성장.

## KPI

2025년 매출 154.9억 원(전사 비중 60.8%)으로 전년(159.9억 원, 69.37%) 대비 절대 매출은 소폭 감소했으나, V2X(CryptoComm) 부문 성장으로 상대적 비중은 축소.
