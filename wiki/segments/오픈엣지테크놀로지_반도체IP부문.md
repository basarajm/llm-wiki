## 사업 내용

오픈엣지테크놀로지는 단일 사업(반도체 설계자산 IP 라이선스·로열티)으로, 크게 두 제품군을 통해 매출을 창출한다.
1. **Total Memory System Solution IP**: OMC™(DDR Memory Controller), OPHY™(DDR PHY), OIC™(On-chip Interconnect)로 구성되며 DRAM 연결·데이터 전송을 최적화.
2. **AI Platform IP for Edge Computing**: ENLIGHT™ NPU IP 브랜드로, 메모리 시스템 IP와 결합해 엣지 AI 반도체 개발을 위한 Turn-key 솔루션 제공.

매출 유형은 라이선스(License)와 로열티(Royalty)로 구분되며, 고객은 Global Tier-1 팹리스와 Design House(TSMC VCA, Samsung Foundry DSP 파트너) 중심이다.

## 경쟁 현황

글로벌 반도체 IP 시장은 [Arm](/companies/Arm)이 프로세서 IP를 중심으로 시장을 주도하며, Imagination, Arteris, Rambus 등이 단일 제품군 중심으로 경쟁한다. 오픈엣지테크놀로지는 메모리 인터페이스(OMC/OPHY) 영역에서 국내 T사·N사 등에 라이선스한 레퍼런스를 보유하고 있으며, NPU(ENLIGHT) 영역은 국내 양산 레퍼런스를 확보한 상태다.
