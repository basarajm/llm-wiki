# 비큐AI RDPLINE사업

## 사업 내용

RDPLINE은 AI 기업 및 산업별 플랫폼 기업을 대상으로 실시간 데이터 공급과 데이터 활용 기술을 제공하는 데이터 파이프라인 플랫폼으로, 국내 최대 규모의 뉴스·멀티모달 데이터를 일괄 또는 실시간 API 형태로 제공한다. 2023년 말부터 국내 대기업과 공급 계약을 체결하며 생성형 AI 학습 데이터 공급 시장을 개척했고, 데이터 공급자와 수요자를 연결하는 RDPLINE 얼라이언스 사업을 운영한다. AI사업본부 해외/국내사업실이 영업을 전담한다.
