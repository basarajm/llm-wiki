## 사업 내용

고객이 필요로 하는 IP의 신규 개발·기능 추가·커스텀 설계, IP Test Chip 개발 및 검증, IP 기술지원(고객 SoC에 대한 integration review, SIPI 분석, test vector 생성 및 디버깅) 등을 제공하는 서비스 사업이다.

## 주요 제품·서비스

- IP 설계(아날로그/디지털), IP Test Chip 개발·검증, IP 기술지원

## 경쟁 현황

자체 IP 포트폴리오를 보유한 팹리스 IP 기업 특유의 부가서비스로, 고객 락인(lock-in) 효과와 신뢰성 확보에 기여한다.
