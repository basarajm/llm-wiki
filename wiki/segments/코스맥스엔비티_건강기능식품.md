# 코스맥스엔비티_건강기능식품

## 개요

[코스맥스엔비티](/companies/코스맥스엔비티)의 단일 사업부문으로, 아래 4개 영역으로 구성된다.

| 구분 | 내용 |
|---|---|
| 기능성 원료 연구개발 | 「건강기능식품에 관한 특별법」상 기능성원료를 천연물 기반으로 연구개발, 제조·유통업체에 공급 |
| 건강기능식품 전문제조(ODM/OEM) | 판매업체 의뢰를 받아 타사 상표 제품 생산·공급 |
| 건강기능식품 전문제조(OBM) | 자체 브랜드·마케팅 Tool을 유통업체에 토탈솔루션으로 공급 |
| 건강기능식품 유통판매 | 유통채널을 통한 직접 판매 |
