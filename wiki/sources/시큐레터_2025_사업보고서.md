## 요약

시큐레터주식회사(SecuLetter Co., Ltd.)의 제11기(2025.01.01~2025.12.31) 사업보고서. 2023년 8월 기술성장기업 특례로 코스닥 상장. 알려지지 않은 악성코드(Unknown Malware) 진단·탐지 전문 보안 소프트웨어 기업으로, 리버스 엔지니어링 기반 MARS(Malware Analysis Reengineering System) 플랫폼을 통해 이메일 보안·파일 보안·CDR(콘텐츠 무해화) 제품을 공급.

|---|---|---|---|
| 매출액 | 1,169 | 1,412 | 2,173 |
| 영업이익 | -4,287 | -7,264 | -5,885 |
| 당기순이익 | -4,288 | -9,436 | -5,757 |

- 자본금(2025년말): 36억 3,580만원 (발행주식총수 7,271,605주, 액면가 500원)
- 2025.06.25 무상감자(최대주주에 대한 차등감자) 실시
- 2025.03.28 대표이사 임차성→정동진 변경
- 신용평가등급(이크레더블): B-(2025.05, 유효기간 2026.05)

## 주요 제품

- SLE(SecuLetter Email Security) — 이메일 보안 구축형
- SLES(SecuLetter Email Service) — 이메일 보안 구독형
- DISARM — MS 365용 클라우드 이메일 보안 (CDR 기반)
- SLF(SecuLetter File Security) — 파일 보안 구축형
- SLCDR(SecuLetter CDR) — 콘텐츠 무해화 솔루션
