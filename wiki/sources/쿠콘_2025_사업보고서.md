## 요약

주식회사 쿠콘(coocon Corporation, 대표이사 김종현)의 제20기 사업보고서. 본점소재지는 서울특별시 영등포구 영신로 220 (케이앤케이디지털타워). 2006년 12월 14일 설립, 2021년 4월 28일 코스닥시장 신규 상장. 웹케시그룹 계열사이며, 개인정보·기업정보·글로벌 API 등 데이터 서비스와 간편결제·전자금융 API 등 페이먼트 서비스를 제공하는 데이터 핀테크 기업이다. 2023년 7월 금융위원회로부터 데이터 전문기관 라이선스를 취득했다.

## 주요 매출처

2025년 4분기 말 기준 주요 매출처는 국민은행, 농협은행, 비바리퍼블리카, 제주은행, 카카오페이 등이며, 5대 매출처 매출 비중은 전체 매출액 대비 약 13.8% 수준.
