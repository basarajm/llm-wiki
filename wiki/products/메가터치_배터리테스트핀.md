## 제품 개요

2차전지 활성화 공정(충전·방전·OCV 등)에서 사용되는 테스트 핀·클립 제품군. 소형부터 중대형
폴리머 리튬이온 배터리까지 대응한다.

## 제품 구성

| 종류 | 사양 |
|---|---|
| CLIP | 소형 폴리머 리튬이온 배터리 활성화공정용 |
| 중대형 CLIP(더블그리퍼) | 중형·대형 폴리머 리튬이온 배터리 활성화공정용 |
| 중대형 CLIP(싱글그리퍼) | 중형·대형 폴리머 리튬이온 배터리 활성화공정용 |
| Single Battery Pin | 리튬이온 Can-Type 원형 소형 배터리용 |
| Coxial Battery Pin(소형) | 동일 축 내 2개 Path 설계 특수핀 |
| Coxial Battery Pin(중·대형) | 충방전 전류 Path + 전압 센싱 Path 통합 설계 |
| Switch Pin | 특정 상황에서 전기신호 On/Off 가능한 설계 |

## 시장 점유율

정량 점유율 데이터는 사업보고서에 미기재(미확인). 배터리 사업부문 매출은 제16기 98.8억원으로
전사 매출의 22.8% 비중(전기 45.0%에서 축소).
