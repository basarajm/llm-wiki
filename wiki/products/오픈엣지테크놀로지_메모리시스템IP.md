## 제품 개요

Total Memory System Solution IP로, DRAM과 SoC 간 고속·안정적 데이터 전송을 담당한다.
- **OMC™(DDR Memory Controller)**: DRAM Command 스케줄링 및 데이터 안정성 보장
- **OPHY™(DDR PHY)**: LPDDR5(6.4~8.5Gbps), GDDR6(14~16Gbps) 등 고속 동작 지원
- **OIC™(On-chip Interconnect)**: SoC 내부 Manager IP와 Subordinate IP 간 데이터 전송 최적화

## 시장 점유율

국내 시장에서 T사·N사 등 주요 팹리스에 라이선스되어 독보적 고객사 레퍼런스를 보유. 별도 정량 점유율은 비공시. 경쟁사로 [Arm](/companies/Arm), Imagination, Arteris, Rambus 등이 있으나 오픈엣지테크놀로지는 메모리 인터페이스 특화 포지션.

## 주요 고객사

Global Tier-1 팹리스(미국 M사·I사, 국내 S사 등) 및 [TSMC](/companies/TSMC)·[삼성전자](/companies/삼성전자) Foundry 파트너 생태계(Design House) — 매출처는 사업보고서상 익명화(A~E사)되어 개별 실명은 미확인.

## 경쟁 제품

- Arm 계열 메모리 인터페이스 IP
- Imagination, Arteris, Rambus 등의 인터커넥트·메모리 IP 제품군

## 시장 트렌드

HBM(고대역폭메모리) 중요성 확대, 칩렛(Chiplet) 구조 확산에 따라 인터페이스 IP 수요 증가. 공정 미세화로 SoC 개발비용이 급증하면서 Tier-1 Track Record를 보유한 IP Vendor에 대한 의존도 확대.
