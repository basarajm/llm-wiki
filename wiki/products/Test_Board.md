## 제품 개요

Test Board(테스트 보드)는 반도체 제조 공정의 마지막 단계인 디바이스 전기적 기능 검사 공정에서 검사 장비와 테스트 소켓 간 전기적·물리적 연결을 위해 사용되는 소모성 부품(Handler Change Kit, Automatic Test Equipment Interface Board, Test Socket 연결부)과, 디바이스 초기 불량 또는 사용자 환경에 따른 불량 발생 가능성을 검사하기 위한 Burn-in Test Board, Evaluation Board, System Level Test Board 등으로 구성된다.
